# Borrador de condiciones de reservación

Versión: `reservation-terms-2026-08-02`

> Borrador sujeto a revisión legal. Completar datos fiscales, domicilio, cancelaciones, reembolsos y URL pública.

## Estado de la reservación

La confirmación indicará expresamente si la reservación está **garantizada** o **no garantizada**. Una reservación no garantizada no debe presentarse como pagada ni como garantía absoluta de disponibilidad.

## Llegada después de las 7:00 p. m.

Cuando la hora estimada de llegada sea posterior a las 7:00 p. m., una reservación no garantizada permanecerá sujeta a disponibilidad. El huésped puede garantizarla realizando el pago mediante la liga segura asociada a su folio, de acuerdo con la política informada antes de aceptar.

Si el huésped no llega a la hora que confirmó, el hotel podrá solicitar una nueva hora estimada. La respuesta debe indicar nuevamente si la reservación continúa no garantizada y, cuando corresponda, ofrecer la liga de pago. Esta regla no permite desconocer una reservación pagada o garantizada.

## Pago

- El importe total, moneda, impuestos y cargos deben mostrarse antes de pagar.
- El pago se procesa por Stripe; el hotel no debe almacenar CVV ni datos completos de tarjeta.
- El estado “pagada” solamente se actualizará después de validar el webhook firmado del procesador.
- Deben definirse cancelaciones, no presentación, devoluciones y tiempos de reembolso.

## Aceptación y evidencia

Antes de completar una reserva web o un pago, el huésped debe consultar estas condiciones y el aviso de privacidad. El sistema conservará folio, versión aceptada, fecha y medio de aceptación. Ninguna cláusula implica renuncia a derechos reconocidos por la legislación mexicana.
